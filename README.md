Token Radar: pre-token protocols ranked by implied value, each with a concrete farm plan. It reads a sealed DefiLlama snapshot, scores every pre-token protocol with one model of the snapshot's own figures, and writes a sortable, filterable dashboard.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input /input/snapshot.json
```
